## Why it was cleaned

The 2026-09-03 scan masked the arm's *moving* links but not the fixed
base/pedestal, so the pedestal stood in the map as an obstacle right where every
plan starts. cuMotion already models the robot's own body from the URDF, so the
pedestal in the world map is a double-count that needlessly invalidates start
states and shrinks free space around the base. Removing it (and stray speckle)
makes the map usable for collision-aware planning without re-scanning — the
captain chose clean-in-place over a re-scan.

## Exactly what was removed

Tool + command (reproducible):
```
nvblx_clean.py cell-2026-09-03.nvblx cell-2026-09-04-cleaned.nvblx \
    --remove-box=-0.60,0.20,-0.32,0.50,-0.65,-0.10 \
    --denoise --min-blocks 4 --self-check
```

| removal | what it was | effect |
|---|---|---|
| crop box `x[-0.60,0.20] y[-0.32,0.50] z[-0.65,-0.10]` (base_link, m) | the robot base/pedestal: a C-bracket of voxels standing on the floor under the arm mount, z −0.64..−0.16, footprint x −0.55..+0.15 / y −0.25..+0.45 | 18 779 weighted voxels set unobserved (399 of them observed surface = the 514 surface voxels removed in total minus the 115 in the 20 denoised components); 84 fully-emptied blocks dropped |
| `--denoise --min-blocks 4` | 20 isolated 26-connected components of ≤3 blocks (1–28 surface voxels each): 3 on the floor plane, 3 at ceiling height, 14 in mid-air — none on the table, tag boards or shelf. Each one's base_link centre / extent / block count: `data/cell-clean-approach-v1/nvblx-clean-audit.txt` (re-run of this recipe; every layer table row-for-row identical to the shipped file) | 32 blocks removed |

Totals: TSDF **11 363 → 11 247 blocks** (−116), occupied surface voxels
**91 292 → 90 778** (−514). The crop box removed nothing above z −0.10, so the
table plane, both tag boards, and the shelf are untouched by it; the 17 denoised
specks above z −0.10 are isolated clusters listed in the audit file — the 3 at
ceiling height 2–19 voxels, the 14 in mid-air 1–10 voxels. The largest mid-air
removal is #10 (10 voxels / 2 blocks, ~16×14×6 cm at base_link ≈(1.55, −1.74,
1.37)), a floating artefact in the map's far corner, ≥ 0.95 m from the plan's
tool path and outside the workspace. The one closest to the plan is #17 (6
voxels ~0.8 m above tag 1 (0.5 m above the hover start), 0.35 m from the tool path — glance there when
clearing the cell). The z≈+2.0 ceiling plane and
all real cell structure are preserved. The column *above* the base is empty in
the scan (the arm was masked there), so there were no "up the column" voxels to
remove.
