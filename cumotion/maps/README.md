# cumotion/maps

Saved nvblox cell maps (`cell-YYYY-MM-DD.nvblx`, TSDF+colour+ESDF in
`base_link`, 2 cm) for `start_cumotion_map.sh`. Committed only when under
~50 MB; larger maps stay in `~/ur10/cumotion/maps/` on the host (the script
searches both, newest first). How they are made: `cams/cellmap/README.md`;
when to re-scan: `RUNBOOK.md` §10.
